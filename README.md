# 📚 Flashcard Quiz App

A simple and interactive **Flashcard Quiz App** designed to help users learn and test their knowledge easily. Users can view questions, reveal answers, and move between flashcards.

## ✨ Features

* 📝 Add new flashcards
* ✏️ Edit existing flashcards
* 🗑️ Delete flashcards
* 👀 Show/Hide answers
* ⬅️ Previous and ➡️ Next flashcards
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 💾 Stores flashcards for easy access

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start creating and studying flashcards!

## 🎯 Purpose

The Flashcard Quiz App helps students improve their learning and revision by providing a simple way to practice questions and answers.
